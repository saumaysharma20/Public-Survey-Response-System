# 📊 Public Survey Response Analyser

**Public Survey Response Analyser** is a Python and Streamlit-based application for survey data cleaning, analysis, visualisation and reporting.

## 🚀 Key Features

- CSV and Excel file upload
- Automatic data classification
- Data cleaning and quality analysis
- Numerical and response analysis
- Group-wise analysis
- Smart insights and recommendations
- Interactive dashboard
- PDF, Excel, CSV and TXT exports

## 🛠️ Technologies Used

Python, Streamlit, Pandas, Plotly Express, OpenPyXL, ReportLab, HTML and CSS.
